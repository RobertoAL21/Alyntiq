Alyntiq — Global Definition of Done

A feature is considered complete only when:

* implementation is functional
* tests exist where appropriate
* existing tests pass
* linting passes
* relevant documentation is updated
* no secrets are introduced
* architectural separation remains intact
* error handling is reasonable
* manual verification steps are documented

A phase is complete only when:

* all phase requirements are implemented
* its Definition of Done is satisfied
* the project runs successfully
* all relevant tests pass
* documentation reflects the final state
* CURRENT_PHASE.md is updated
* no future phase functionality was introduced unnecessarily
